# Ingenieria — LevelYourDraw

## 1. Lectura obligatoria

1. `CONSTITUTION.md` 2. `PLAN.md` 3. `DISENO.md`.

## 2. Cambios

- Un cambio = codigo + actualizacion de `PLAN.md`. Sin plan desactualizado.
- Un defecto se registra con causa raiz, no se esconde en una tarea nueva.

## 3. Revision

- Quien implementa no aprueba su propio trabajo.
- La IA propone; la validacion humana decide el merge.
- Sin secretos en contexto, prompts ni logs.

## 4. Diseno

- Los valores numericos se copian del sistema de diseno. Ver `DISENO.md`.
- Si el diseno contradice los datos disponibles, se reporta y se corrige el documento antes que el codigo.

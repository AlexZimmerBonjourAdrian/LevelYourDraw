# LevelYourDraw

Generador de briefs y retos de diseño de personajes para Android. Supera el bloqueo creativo con metodologías de la industria: los 4 datos, briefs narrativos y estudio de estilo. Exporta tus consignas en PNG transparente para superponer en tu lienzo o captura fotos con el reto integrado para compartir el proceso en tus redes sociales.
